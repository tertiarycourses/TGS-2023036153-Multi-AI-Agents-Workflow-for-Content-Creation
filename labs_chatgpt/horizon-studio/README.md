# horizon-studio — your working folder

Open this folder in Codex as a local project and keep it from Lab 1 to Lab 14.

- `data/` — every brief and data file the labs use, ready to read
- `web/site/index.html` — the local copy of Horizon's website
- `research/` `strategy/` `content/` `reports/` `review/` — empty; the agents fill them



Media (`env.example`, the sample video) stay in their lab's `assets/` — the lab tells you when you need them.
