# horizon-studio — your working folder

Open this folder in Claude (Add folder) or run `claude` in a terminal here and keep it from Lab 1 to Lab 12.

- `data/` — every brief and data file the labs use, ready to read
- `web/site/index.html` — the local copy of Horizon's website
- `research/` `strategy/` `content/` `reports/` `review/` — empty; the agents fill them

Kits and media (the publisher kit, `env.example`, the sample video) stay in their lab's `assets/` — the lab tells you when to copy them.
