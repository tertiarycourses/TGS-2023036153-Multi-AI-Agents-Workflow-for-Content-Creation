# Fact-check

1. List every claim with a number, age, date, rate, cap or rule.
2. Find each one in data/facts-2026.md. Same value, same year?
   - yes -> VERIFIED (quote the row)
   - no, or not on the sheet -> UNVERIFIED
3. Never correct a figure from memory. An UNVERIFIED claim is removed or
   sent to a person — it is never published.
4. Fees, client returns and "typical" or "average" returns are always
   UNVERIFIED for public content.
5. Output: a table (claim, value in draft, facts-sheet value, VERIFIED /
   UNVERIFIED) and a one-line verdict.
