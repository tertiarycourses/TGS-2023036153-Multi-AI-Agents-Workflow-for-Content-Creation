# Channel formats

Follow data/channel-formats.md for the shape of each channel:
- LinkedIn: 120-250 words, a first line that stands alone, 3 hashtags,
  short disclaimer last.
- Facebook: 60-150 words, warm, ends with a question, one image idea + alt text.
- Newsletter: subject < 50 chars, preview < 90, one tip, one nudge, one CTA,
  footer with unsubscribe, address and disclaimer.
- YouTube: 60-90 s, 5-7 scenes (seconds, title, text); description with
  chapters, link, disclaimer, AI disclosure; 5-8 tags.

Every link carries UTM tags:
?utm_source=<channel>&utm_medium=<social|email|video>&utm_campaign=know-your-number

Save each piece as one file with the frontmatter in data/publishing-spec.md.
